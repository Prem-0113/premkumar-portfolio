# Premkumar V — AI Developer & Python Backend Developer Portfolio

A personal brand portfolio website crafted with an editorial aesthetic inspired by Ali Abdaal's warm personal site (warm cream canvas, Fraunces serif headings, sunny yellow circular hero cutout with speech bubble accent, and playful hand-drawn elements).

## 🚀 Live Local Preview

To preview the portfolio locally, you can use Python's built-in HTTP server:

```bash
cd /home/prem/.gemini/antigravity/scratch/premkumar-portfolio
python3 -m http.server 8000
```

Then open your browser at `http://localhost:8000`.

Alternatively, simply double-click or open `index.html` in any web browser.

## 🌐 Free One-Click Deployment Options

### GitHub Pages:
1. Create a repository on GitHub (e.g. `premkumar-portfolio`).
2. Push all files to the `main` branch.
3. In repository Settings > Pages, select `main` branch and `/ (root)`.
4. Your site will be live at `https://<username>.github.io/premkumar-portfolio/`.

### Vercel / Netlify:
- Simply drag and drop the `premkumar-portfolio` folder into the Netlify or Vercel dashboard for immediate zero-config deployment.
